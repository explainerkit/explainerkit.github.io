# ExplainerKit website

This repository serves https://explainerkit.github.io/, the home page and documentation for ExplainerKit 0.1.0-alpha.1. Every file here is built, and the library itself lives at [prajwalsouza/ExplainerKit](https://github.com/prajwalsouza/ExplainerKit), whose `site/` folder holds the same website.

GitHub Pages serves this repository's main branch from its root. The empty `.nojekyll` file stops Pages from running Jekyll, which would otherwise hide files whose names begin with an underscore.

The code is released under the MIT license in `runtime/LICENSE`. Footage, data and recorded instruments keep their own terms, listed on the [credits page](docs/credits.html).
